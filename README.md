# Access TV - Accessible TV Streaming Addon for NVDA

**Access TV** adalah addon resmi untuk screen reader NVDA yang dirancang khusus untuk mendengarkan siaran langsung televisi streaming (*Audio-First*) dengan aksesibilitas penuh bagi pengguna tunanetra.

---

## Fitur Utama

- **Audio-First Murni:** Siaran streaming HLS (`.m3u8`) diproses audionya secara ringan dan stabil menggunakan integrasi pustaka BASS x86/x64 tanpa membebani kartu grafis atau CPU komputer.
- **Ratusan Saluran TV Aktif:** Menyediakan puluhan saluran nasional & daerah Indonesia (TVRI Nasional & Provinsi, CNN Indonesia, CNBC Indonesia, Nusantara TV, Rodja TV, dll.) serta siaran internasional dari belasan negara (Malaysia, Singapura, Arab Saudi, Turki, Inggris, Amerika, Jerman, Jepang, dll.).
- **Tambah Saluran Kustom Sendiri:** Pengguna dapat menambahkan tautan streaming TV (`.m3u8`) pribadi melalui antarmuka dialog yang ramah pembaca layar.
- **Sambung Ulang Otomatis (*Auto-Reconnect*):** Otomatis menyambungkan kembali siaran hingga 3 kali jika koneksi internet sempat tersendat.
- **Sistem Favorit Persisten:** Simpan stasiun TV favorit secara permanen di profil pengguna NVDA.
- **Slider Volume Terintegrasi:** Kontrol level volume yang halus dan langsung dilaporkan oleh NVDA.

---

## Pintasan Keyboard Global (Shortcut)

- **`Ctrl + Windows + A`** : Membuka antarmuka utama dialog Access TV dari aplikasi apa pun.
- **`Ctrl + Windows + Shift + S`** : Menghentikan (*Stop*) siaran seketika tanpa membuka dialog.
- **`Ctrl + Windows + Shift + A`** : Mengumumkan nama siaran TV yang sedang diputar dan status volume saat ini.

---

## Persyaratan Sistem

- **Screen Reader:** NVDA versi **2025.1.0** ke atas.
- **Sistem Operasi:** Windows 10 / Windows 11 (32-bit atau 64-bit).
- **Koneksi Internet:** Diperlukan untuk mengakses aliran siaran streaming TV.

---

## Cara Pemasangan

1. Unduh berkas **`AccessTV.nvda-addon`** dari menu [Releases](https://github.com/Mahfud-PG/access-tv/releases).
2. Tekan **Enter** pada berkas `.nvda-addon` tersebut.
3. Konfirmasi instalasi pada dialog NVDA dan setujui untuk me-restart NVDA.
4. Tekan **`Ctrl + Windows + A`** untuk mulai menikmati siaran televisi streaming.
