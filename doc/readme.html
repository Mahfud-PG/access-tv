Panduan Pengguna Access TV

Versi: 1.2.0

Pengembang: Mahfud Pg & Tim Studio Hermes

1. Pengenalan

Access TV adalah addon resmi untuk screen reader NVDA yang dirancang khusus untuk memutar siaran televisi streaming secara langsung (Audio-First) dengan aksesibilitas penuh bagi pengguna tunanetra. Mendukung filter 16 negara (Indonesia, Malaysia, Singapura, Arab Saudi, Palestina, Turki, Inggris, Amerika Serikat, Jerman, Jepang, dll.) serta lebih dari 500 saluran TV aktif.

2. Fitur Baru Versi 1.2.0

  • Saluran Kustom Pribadi: Pengguna dapat menambahkan tautan streaming TV (.m3u8) sendiri melalui tombol Tambah Saluran Kustom.... Saluran ini tersimpan permanen di folder profil NVDA dan tidak akan hilang saat addon diperbarui.
  • Sambung Ulang Otomatis (Auto-Reconnect): Jika koneksi Wi-Fi tersendat atau terputus sementara, Access TV akan otomatis mencoba menghubungkan kembali siaran hingga 3 kali tanpa perlu menekan tombol putar manual.

3. Pintasan Keyboard Global (Shortcut)

  • Ctrl + Windows + A : Membuka antarmuka utama Access TV dari aplikasi apa pun.
  • Ctrl + Windows + Shift + S : Menghentikan siaran seketika tanpa membuka dialog.
  • Ctrl + Windows + Shift + A : Mengumumkan nama siaran TV yang sedang diputar beserta volume saat ini.

4. Alur Navigasi Dialog

  1. Kotak Pencarian: Ketik kata kunci (misal: "TVRI", "Kompas", "CNN") untuk memfilter saluran secara langsung. Tekan Enter untuk langsung memutar saluran pertama yang ditemukan.
  2. Pilih Negara: Gunakan Panah Atas / Bawah untuk mengganti negara siaran (Default: Indonesia, termasuk opsi Saluran Kustom Pribadi).
  3. Filter Favorit: Centang untuk hanya menampilkan saluran yang ditandai sebagai favorit.
  4. Daftar Saluran: Jelajahi saluran dengan Panah Atas / Bawah. Tekan Enter atau Spasi untuk memutar.
  5. Tombol Putar / Stop: Memulai atau menghentikan siaran.
  6. Tombol Tambah/Hapus Favorit: Menyimpan saluran ke daftar favorit permanen.
  7. Tombol Tambah Saluran Kustom: Membuka dialog untuk menempelkan URL siaran TV sendiri.
  8. Tombol Hapus Saluran Kustom: Menghapus saluran pribadi yang sedang dipilih.
  9. Slider Volume: Gunakan Panah Kiri / Kanan untuk mengatur volume (0% - 100%).
  10. Tombol Tutup: Menutup dialog (Escape). Siaran akan tetap berbunyi di latar belakang.
